# **Bulk Actions**

You can perform bulk actions on bookmarks from the bookmark list.

1. Click on the **`Select multiple`** button, which will expand the bulk selection toolbar.
2. Checkboxes will now appear next to each bookmark in the list.
3. Select any bookmarks you want to perform actions on by checking the box next to them.
4. While the bulk selection toolbar is open, you can:
    - Continue applying filters to the bookmark list.
    - Sort the list.
    - Move between pages.

Selections will be **remembered** even if they are no longer visible due to filtering, sorting, or pagination.  
The bulk selection toolbar displays:
- The **total number** of selected bookmarks.
- The **number of selected bookmarks currently visible** on the screen.

All selected bookmarks will be affected when performing a bulk action.

## **Bulk Actions Available**

### **Bulk Delete Bookmarks**
This action will **permanently delete** all selected bookmarks.

### **Bulk Tag Add**
This action will add all tags selected in the bulk toolbar to the selected bookmarks.
- Any tags already assigned to a bookmark will be ignored (you won’t "double tag").

### **Bulk Tag Remove**
This action will remove all tags selected in the bulk toolbar from the selected bookmarks.
- If a tag is not assigned to a bookmark, it will be ignored and will not cause an error.
- You can add a non-existing tag to the bulk tag removal list. This won’t cause an error but will have no effect.
